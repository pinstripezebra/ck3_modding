
# Light Magic — Tree 1: The Battlemage
# Combat-focused branch: bigger personal power, then two paths (defensive wards
# / efficient casting) that both terminate in bonuses to the mage regiments
# (wandering_mages, mage_squadron, mage_regiment — all type = magi).
# These magi modifiers are only ever granted through this lifestyle, which is
# only valid for characters with a Lore of Magic trait, so vanilla heavy
# infantry (and Elder Magic's own undead MaA) is never buffed by them.
