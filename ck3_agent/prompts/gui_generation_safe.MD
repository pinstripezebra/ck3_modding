CK3 GUI Safe Generation Prompt

Use this prompt when asking for GUI code changes:

"Generate CK3 .gui code using strict layout safety rules:

1. Keep all text/buttons inset by >= 8px from parent edges.
2. Do not use full-screen decorative overlays.
3. Use at most 3 decorative texture layers per panel.
4. Separate containers by responsibility: header, content list, actions.
5. Keep naming descriptive and unique.
6. Include a close button for modals.
7. Prefer robust/simple meter rendering first; visual polish second.

Output only one complete .gui snippet."
